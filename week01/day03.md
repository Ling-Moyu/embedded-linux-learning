# Day 3 · 重定向与管道

## 三个最值钱的发现
1. 报错走的是 stderr，和正常输出是两根管子 —— 2>/dev/null 就是把错误扔黑洞
2. uniq 只压"相邻"的重复行，所以它前面必须先 sort(排序)  -->uniq -c计数  sort -rn按数字倒序排
3. cut/awk 的列号取决于数据怎么切的 —— 第 4 关 f5 取到 temp、修正为 f4 的过程
4. for i in 1 2 3 4 5; do ... done循环
5. $(()) 是算术运算，$((RANDOM%3)) = 取随机数除以 3 的余数（所以只有 0/1/2 三种）
6. >>追加写入,>覆盖写入



## 今天最坑的一个报错
- awk 后面漏了空格 → bash 把整串当成文件名去找 → "No such file or directory"
- 教训：见到这个报错先逐字符检查命令拼写和空格

## 一句话总结管道
每个命令只做一件小事，| 把它们串成流水线。
